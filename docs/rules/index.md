# Rules

Guides to Agent Helm’s rules for Git, safety, writing and responsive, accessible design without generic AI defaults. Each page explains the rule’s scope and how it guides agents in your project.

| Rule | What it guides |
|---|---|
| [Git]({{ '/docs/rules/git.html' | relative_url }}) | Local work, commits, checks and publication. |
| [Safety]({{ '/docs/rules/safety.html' | relative_url }}) | Authorization, preserving user work and consequential effects. |
| [Writing]({{ '/docs/rules/writing.html' | relative_url }}) | Clear prose, useful detail and reference links. |
| [Design]({{ '/docs/rules/design.html' | relative_url }}) | Interface structure, responsiveness, accessibility and navigation. |

[Adopt]({{ '/docs/commands/adopt.html' | relative_url }}#available-rules) installs Git and Safety together. Writing and Design are independent options.
