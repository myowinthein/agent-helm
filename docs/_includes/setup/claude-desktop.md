## Install

1. Open **Customize → Plugins** in Claude.
2. Choose **Add plugin → Add marketplace → Add from a repository**.
3. Enter `myowinthein/agent-helm`, select the repository or **Use “myowinthein/agent-helm”**, then click **Sync**.
4. Find **Agent Helm** in the marketplace and click **Add**.
5. Open **Yours** and check that the plugin is enabled and lists all ten skills.
6. Start a fresh chat in your project workspace. Type `/` and select a Helm workflow, such as `log`, `test` or `ship`.

## Update

1. Open **Customize → Plugins → Yours**.
2. Open Helm's **More actions** menu and choose **Check for updates**.
3. If offered, open the plugin and click **Update**. Check its version, then start a fresh chat.

## Uninstall

1. Open **Customize → Plugins → Yours**.
2. Open Helm's **More actions** menu, choose **Remove**, then confirm **Remove**.
3. Check that the card is gone from **Yours** and the workflows are absent from a fresh chat.
