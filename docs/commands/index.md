# Commands

Guides to using Agent Helm at different points during project development. Each command page explains how to start, what happens along the way and what results to expect.

Commands share one question mechanism (QM) for choices, multiple selections, missing details and plan reviews. Helm uses the preferred native control where supported, then a compatible native alternative when needed. If none is suitable, it presents the same choices in conversation and waits for your reply. A confirmed presentation failure follows the same ordered alternatives; silence, rejection and cancellation never trigger another presentation. A recommended or preselected answer never approves work; selection and action approval retain each command's existing boundaries.
