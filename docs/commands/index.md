# Commands

Guides to using Agent Helm at different points during project development. Each command page explains how to start, what happens along the way and what results to expect.

| When you want to… | Command |
|---|---|
| Give agents better project context | [log]({{ '/docs/commands/log.html' | relative_url }}) |
| Install or update project rules | [adopt]({{ '/docs/commands/adopt.html' | relative_url }}) |
| Check environment configuration and Git protection | [env]({{ '/docs/commands/env.html' | relative_url }}) |
| Find gaps in automated test protection | [test]({{ '/docs/commands/test.html' | relative_url }}) |
| Improve code structure while preserving behavior | [refactor]({{ '/docs/commands/refactor.html' | relative_url }}) |
| Create or refresh a README | [manifest]({{ '/docs/commands/manifest.html' | relative_url }}) |
| Draft or review public legal documents | [legal]({{ '/docs/commands/legal.html' | relative_url }}) |
| Review and standardize commit messages | [normalize]({{ '/docs/commands/normalize.html' | relative_url }}) |
| Publish reviewed work or prepare a release | [ship]({{ '/docs/commands/ship.html' | relative_url }}) |
| Preserve a project for later recovery | [archive]({{ '/docs/commands/archive.html' | relative_url }}) |
