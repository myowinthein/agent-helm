# Commands

Guides to using Agent Helm at different points during project development. Each command page explains how to start, what happens along the way and what results to expect.

Commands share one question mechanism (QM) for choices, multiple selections, missing details and plan reviews. Helm uses native question controls when your agent supports the required interaction. Otherwise it presents the same choices in conversation and waits for your reply. A recommended or preselected answer never approves work; selection and action approval retain each command's existing boundaries.
