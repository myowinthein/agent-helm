## Install

1. Open the sidebar **Plugins** icon to reach **Customize → Plugins**.
2. Choose **Add → Add a marketplace**. Enter `myowinthein/agent-helm` in **Source**, then click **Add marketplace**.
3. Select **Personal** and find the Helm marketplace. Click **+** beside Helm to install it. It may appear as `agent-helm` or **Agent Helm**.
4. Open Helm under **Installed**. Check its **Version** and that all ten skills are enabled.
5. Start a fresh chat in your project workspace. Type `$` and select a Helm workflow, such as `log`, `test` or `ship`.

## Update

1. Open **Settings → Integrations → Plugins → Marketplace**.
2. Find the Helm marketplace and click **Upgrade**.
3. Reopen the plugin details and check its version and enabled skills.
4. Start a fresh chat to check workflow availability.

## Uninstall

1. Open **Customize → Plugins → Personal**.
2. Open Helm's **…** menu and choose **Uninstall**.
3. Check that Helm is gone from **Installed** and its workflows are absent from a fresh chat's `$` picker.
